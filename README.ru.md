# Прошивка намоточного станка

[English](README.md) | Русский | [Українська](README.uk.md)

Прошивка Arduino для двухосевого станка намотки катушек: **главный вал** (шпиндель) на шаговом двигателе вращает каркас катушки, а **раскладчик провода** (каретка на ходовом винте) на отдельном шаговом двигателе равномерно укладывает провод по ширине катушки, механически синхронизированный с вращением главного вала. Управление и индикация — через ЖК-дисплей 16x2 и энкодер с кнопкой.

## Аппаратная часть

| Функция | Драйвер / компонент | Выводы (Arduino) |
|---|---|---|
| Двигатель главного вала | DRV8825, **микрошаг 16x** | STEP `9`, DIR `8`, ENABLE `10` |
| Двигатель раскладчика провода | DRV8825, **микрошаг 8x** | STEP `11`, DIR `6`, ENABLE `5` |
| Энкодер | квадратурный + кнопка | A `3`, B `4`, кнопка `2` |
| Концевой выключатель раскладчика | концевик (input pullup) | `7` |
| ЖК-дисплей | символьный 16x2, 4-битный режим | RS `A0`, EN `A1`, D4-D7 `A2-A5` |

Двигатель: 200 полных шагов/оборот (1.8°). Шаг ходового винта раскладчика: 1 мм.

- Разрешение главного вала: 200 × 16 = **3200 микрошагов/оборот**
- Разрешение раскладчика: 200 × 8 = 1600 микрошагов/оборот → **1600 шагов/мм** хода каретки (0.625 мкм/шаг)

## Основные возможности

### Синхронизация раскладчика по алгоритму Брезенхэма
Вместо отдельного таймера для раскладчика провода, каждый микрошаг главного вала увеличивает накопитель на фиксированный коэффициент (`wgRatio`, вычисляется из диаметра провода). Когда накопитель превышает количество шагов, соответствующее полному обороту главного вала, раскладчик получает один шаг вперёд. Это удерживает шаг укладки провода строго привязанным к вращению шпинделя независимо от скорости, без дрейфа от независимых таймеров. Накопитель сбрасывается циклом `while` (а не одиночным `if`), поэтому синхронизация сохраняется точно даже если коэффициент когда-либо потребует больше одного шага раскладчика на шаг главного вала.

### Автоматический реверс слоя
Прошивка отслеживает положение раскладчика в пределах текущего слоя (`currentLayerPosition`). При достижении длины катушки (`coilLengthMM`) направление хода меняется на противоположное, а счётчик слоёв увеличивается — катушка формируется последовательными слоями «туда-сюда» автоматически, без вмешательства оператора в режимах AUTO/SEMI-AUTO.

### Настраиваемое направление намотки (слева направо / справа налево)
По умолчанию первый проход раскладчика идёт **слева направо**, от концевого выключателя. Можно настроить и обратный порядок — **справа налево**, в сторону выключателя. В режиме «справа налево» заданное нулевое смещение (`zeroOffsetMM`) интерпретируется как расстояние от выключателя до *дальней* стартовой точки, а длина катушки автоматически ограничивается этим смещением — это не позволяет каретке получить команду на движение за физический концевик.

### Плавный разгон по S-кривой (smoothstep)
Запуск и остановка двигателя происходят плавно, в течение ~1 секунды, по S-образной кривой (`3x²-2x³`), а не мгновенным скачком до целевой скорости — это снижает механические удары и пропуски шагов на высокой скорости.

### Изменение скорости «на лету»
В любом рабочем режиме поворот энкодера изменяет `targetRPS` с шагом ±0.1 об/с прямо во время работы, без остановки двигателя. Если довести значение до 0, происходит контролируемая остановка; при дальнейшем повороте направление главного вала меняется на противоположное.

### Автоматическая остановка по числу витков
В режимах SEMI-AUTO и AUTO станок автоматически замедляется и останавливается по достижении заданного числа витков.

### Ограничение реверса в ручном режиме
В режиме MANUAL при реверсе шпинделя двигатель автоматически останавливается, когда счётчик витков возвращается к 0, не позволяя счётчику уйти в отрицательные значения.

### Последовательность базирования и установки нуля
При включении питания прошивка требует базирования раскладчика провода по физическому концевому выключателю, после чего оператор может подвести каретку и подтвердить «нулевое смещение» — фактическую стартовую позицию намотки относительно этого выключателя (шаг 0.1 мм, диапазон 0–200.0 мм).

## Режимы работы

| Режим | Назначение |
|---|---|
| `HOMING_MODE` | Подводит раскладчик к концевому выключателю для установки физического нуля (выполняется один раз при включении, по нажатию кнопки). |
| `ZERO_SET_MODE` | Оператор задаёт смещение от физического выключателя до логической стартовой позиции намотки. |
| `MENU_MODE` | Энкодер листает пункты MANUAL / SEMI-AUTO / AUTOMATIC / SETUP; кнопка выбирает пункт. |
| `MANUAL_MODE` | Свободный ход шпинделя, вперёд или назад, скорость регулируется на лету, нет автостопа по виткам (останавливается на 0 витках при реверсе). |
| `SEMI_AUTO_MODE` | Работает и автоматически останавливается по заданному числу витков, но требует повторного нажатия кнопки для продолжения между слоями или после завершения. |
| `AUTO_MODE` | Полностью автоматический режим: непрерывная намотка всех слоёв до заданного числа витков, затем остановка. |
| `SETUP_MODE` | Экран настройки из 4 параметров (см. ниже). |

## Параметры настройки

Доступны через пункт меню SETUP, переключаются кнопкой энкодера:

1. **Диаметр провода** — 0.05–1.00 мм, шаг 0.01 мм. Ограничен 1.00 мм; более толстый провод предполагается наматывать вручную. Определяет передаточное отношение раскладчик/шпиндель.
2. **Длина катушки** — 1–500 мм, шаг 1 мм. Ширина хода раскладчика на один слой. Автоматически ограничивается нулевым смещением при направлении намотки «справа налево».
3. **Целевое число витков** — 1–9999, целые витки. Также используется для оценки и отображения необходимого числа слоёв (`витки / (длина катушки / диаметр провода)`, с округлением вверх).
4. **Направление намотки** — слева направо (по умолчанию) или справа налево, отображается на ЖК-дисплее стрелками.

## Скорость

- Регулируемый диапазон: **от 0 до ±3.0 об/с** (оборотов в секунду), шаг 0.1 об/с через энкодер во время работы.
- При микрошаге 16x это соответствует до 9600 микрошагов/с на главном валу — с запасом в рамках электрических ограничений DRV8825 и разрешения таймера прошивки 10 мкс.
- Знак `targetRPS` задаёт направление вращения шпинделя; величина — скорость.

## Типичные сценарии использования

**Намотка простой однослойной катушки (режим AUTO)**
1. Включить питание → выполнить базирование раскладчика по концевому выключателю (нажатием кнопки).
2. Подвести каретку к нужному стартовому смещению от выключателя, подтвердить.
3. В SETUP задать диаметр провода, длину катушки и целевое число витков.
4. В меню выбрать AUTOMATIC и нажать кнопку для старта — станок разгоняется, наматывает полное число витков через столько слоёв, сколько нужно, автоматически меняя направление на границах слоёв, и сам останавливается по достижении заданного числа витков.

**Ручная намотка / доработка**
- Режим MANUAL для прямого управления без таймера: старт/стоп кнопкой, регулировка скорости на лету энкодером, реверс — проведя скорость через 0. Полезно для ручной укладки нестандартного провода или доработки частично намотанных катушек.

**Пошаговая намотка под контролем оператора (SEMI-AUTO)**
- Тот же автоматический подсчёт витков и автостоп, что и в режиме AUTO, но рассчитан на операторов, которые хотят делать паузы/проверки между слоями, а не оставлять всю катушку наматываться без присмотра.

**Катушки с намоткой справа налево**
- Для каркасов/оснастки, где провод нужно укладывать начиная с дальнего конца и заканчивая у концевого выключателя, установите направление намотки «справа налево» в SETUP. Прошивка будет трактовать заданное нулевое смещение как дальнюю стартовую точку и не допустит такой длины катушки, которая привела бы каретку за концевой выключатель.

## Особенности реализации прошивки

- Шаги главного вала и синхронизация раскладчика провода происходят внутри одного прерывания сравнения `TIMER1`, срабатывающего каждые 10 мкс; импульс шага раскладчика формируется прямо внутри обработчика (блокирующая задержка ~3 мкс) при переполнении накопителя Брезенхэма, поэтому синхронизация со шпинделем сохраняется без дополнительного таймера или опроса.
- `stepCount` (основной счётчик витков) читается основным циклом только в короткой критической секции `cli()/sei()`, поскольку это многобайтовое значение, изменяемое внутри прерывания.
- Сигналы энкодера и кнопки обрабатываются прерываниями по изменению состояния вывода с простым подавлением дребезга (150 мс для кнопки).
